## 🚀 QUICK DEPLOYMENT

### Deploy Backend (Node.js API)
```bash
# Option 1: Railway.app (Easiest)
cd server
railway link
railway deploy

# Option 2: Heroku
heroku create career-ai-api
git push heroku main

# Option 3: Docker
docker build -t career-ai-api .
docker run -p 4000:4000 career-ai-api
```

### Deploy Frontend (React App)
```bash
# Vercel (Fastest)
cd career-ai
vercel deploy

# Or: Build then upload to hosting
npm run build
# Upload 'dist' folder to any hosting
```

### Build Mobile APK
```bash
cd mobile
npm install -g eas-cli
eas build --platform android
# Download APK and install on device
```
