Choose one:

**Option A: Railway (EASIEST & RECOMMENDED)**

```bash

```

**Option C: Docker**
```bash
docker build -t career-ai .
docker run -p 5173:5173 -p 4000:4000 career-ai
```

### **Step 5: Build Mobile App** (10 minutes)
```bash
npm install -g eas-cli
cd mobile
eas build --platform android
# Download APK from EAS console
```

## 📝 ENVIRONMENT SETUP

Create `.env` file in project root:
```env
# Frontend
VITE_API_URL=http://localhost:4000
VITE_APP_NAME=Career AI
VITE_THEME=dark

# Backend
PORT=4000
NODE_ENV=development
JWT_SECRET=your_super_secret_key_change_in_production
DATABASE_URL=file:./data/dev-db.json
CORS_ORIGIN=http://localhost:5173,http://localhost:3000

# Production
VITE_API_URL=https://career-ai-api.railway.app
NODE_ENV=production
JWT_SECRET=your_production_secret_key
```
