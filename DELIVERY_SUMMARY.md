### **Change Colors**
Edit `src/global.css`:
```css
--primary: #3b82f6;     /* Primary color */
--secondary: #10b981;   /* Secondary color */
--danger: #ef4444;      /* Danger color */
```

### **Add More Jobs**
Edit `server/expanded-jobs-db-250.js`:
```javascript
{ id: 291, title: 'Job Title', company: 'Company', ... }
```

### **Add More Templates**
Edit `src/assets/pages/ResumeLab.jsx`:
```javascript
{ name: 'Template Name', bg: '#color', text: '#color', accent: '#color' }
```

### **Change Theme Default**
Edit `src/App.jsx`:
```javascript
const [theme, setTheme] = useState('light');  // or 'dark'
```

### **Update API URL**
Edit `src/api.js`:
```javascript
const API_URL = 'https://your-api-url.com';
```
